# 16. ENGINEERING GRAPHICS VOCABULARY — Standard Glossary

| Term | Symbol / Notation | Definition |
|:---|:---:|:---|
| **Reference Line** | $XY$ | The line of intersection between the Vertical Plane (VP) and Horizontal Plane (HP). |
| **Horizontal Plane** | HP | The horizontal principal reference plane. Top View is projected on HP. |
| **Vertical Plane** | VP | The vertical principal reference plane. Front View (Elevation) is projected on VP. |
| **Front View (Elevation)** | $a', b', c'$ | The orthographic projection of an object onto the Vertical Plane (VP). |
| **Top View (Plan)** | $a, b, c$ | The orthographic projection of an object onto the Horizontal Plane (HP). |
| **Side View (Profile View)** | $a'', b'', c''$ | The orthographic projection of an object onto the Profile Plane (PP). |
| **True Length** | $TL$ | The actual physical distance between two end points in 3D space. |
| **True Angle to HP** | $\theta$ | The inclination angle made by the true line with the Horizontal Plane. |
| **True Angle to VP** | $\phi$ | The inclination angle made by the true line with the Vertical Plane. |
| **Apparent Angle to HP** | $\alpha$ | The angle made by the Front View ($a'b'$) with the reference line $XY$. |
| **Apparent Angle to VP** | $\beta$ | The angle made by the Top View ($ab$) with the reference line $XY$. |
| **Horizontal Trace** | $HT$ | The point of intersection of the line (or its extension) with the Horizontal Plane. |
| **Vertical Trace** | $VT$ | The point of intersection of the line (or its extension) with the Vertical Plane. |
| **Locus Line** | $h_b, d_b$ | The path traced by an end point as it rotates while maintaining constant height/depth. |
| **Projector** | - | A straight line drawn perpendicular to $XY$ connecting corresponding points in FV and TV. |
