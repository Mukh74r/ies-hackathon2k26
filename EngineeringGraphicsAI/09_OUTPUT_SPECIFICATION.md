# 09. OUTPUT SPECIFICATION — Response Architecture

Every AI response generated by the backend must deliver complete information across all required sections:

---

## 1. RESPONSE SECTION BREAKDOWN

```
├── 1. Problem Classification & Meta
│    ├── Topic
│    ├── Method
│    └── Quadrant
│
├── 2. Data Synthesis
│    ├── Given Data Map (Numbered Keys)
│    └── Computed Answers Array
│
├── 3. Engineering Reasoning & Analysis
│    ├── Problem Summary
│    ├── Step-by-Step Rationale
│    └── Trigonometric Formulae Applied
│
├── 4. Construction Steps (Atomic Step Sequence)
│    ├── Step 1 to N: Title, Description, Action, Parameters
│
├── 5. Geometric Engine Payload
│    ├── Points Array (x, y, label, anchor, step)
│    ├── Lines Array (from, to, style, label, step)
│    ├── Loci Array (through, direction, extent, step)
│    ├── Arcs Array (center, radius, startAngle, endAngle, step)
│    └── Traces Array (HT, VT)
│
├── 6. Mathematical Verification
│    ├── Vertical Alignment Check (a' & a, b' & b)
│    └── Locus Height Consistency Check
│
└── 7. Examiner & Pedagogical Guidance
     ├── Key Drafting Rules
     ├── Common Student Mistakes
     └── Exam Marking Tips
```
