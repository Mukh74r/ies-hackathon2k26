## 🚀 Executive Overview

**DeepHub AI** is an enterprise-grade, privacy-first academic intelligence suite and pedagogical operating system designed to automate administrative workloads for teachers and empower students with Socratic, step-by-step cognitive learning.

Unlike generic AI wrappers or simple chatbots, DeepHub AI incorporates **curriculum-aligned blueprints (CBSE, ICSE, IB, Cambridge IGCSE, State Boards)**, **vector KaTeX LaTeX rendering**, **client-side DOCX/PPTX binary generation**, **anti-cheating quiz randomization**, and an ultra-fast **Turbo Brain local caching engine**.

## 👨‍🏫 How Educators & Schools Use DeepHub AI

The **Educator Suite (Teaching Studio)** automates 85% of repetitive administrative and exam preparation tasks:

### 1. 📝 Question Paper Generator (QPG)
- **Multi-Section Blueprints**: Generate Section A (MCQs / Assertion-Reason), Section B (Short Answer), Section C (Long Derivations), and Section D (Case Studies).
- **Difficulty Calibrations**: Real-time adjustment between *Easy (30%)*, *Medium (50%)*, and *Application / HOTS (20%)*.
- **1-Click Word Export**: Export fully styled exam papers with official school headers, watermark grids, and student signature lines.

### 2. ⏱️ 45-Minute Lesson Plan Builder
- **Pedagogical Structure**: Builds structured 45-minute lesson timelines broken into *Hook & Introduction (5m)*, *Concept Instruction (20m)*, *Guided Practice (15m)*, and *Exit Ticket Assessment (5m)*.
- **NEP-2020 & Blooms Taxonomy**: Automatically tags learning outcomes from *Remembering* to *Creating*.

### 3. 📊 Presentation Deck & PPT Generator
- **Visual Slide Templates**: Select from *Midnight Scholar*, *Oceanic Teal*, *Sunset Amber*, or *Minimal Monochrome* themes.
- **Scholarly Hierarchy**: Creates slide headers, bullet points, reflection summaries, and speaker presentation notes.
- **Native `.pptx` Export**: 1-Click download of editable PowerPoint presentations.

### 4. 📜 The Document Secretary
- **Administrative Circulars**: Generate formal field trip permission slips, disciplinary warning letters, achievement certificates, and holiday notices.
- **Custom Institutional Letterhead**: Upload school crests, specify official contact details, and export formatted `.docx` notices.

### 5. 🔀 Quiz Shuffler (Anti-Cheating Engine)
- Input any question bank to instantly generate **Set A, Set B, Set C, and Set D** with scrambled options and questions.
- Generates an **Official Master Answer Key** for rapid grading.

## 🎓 How Students Use DeepHub AI

When toggled to **Student Studio (Learning Lab)**, DeepHub AI switches into an active cognitive learning companion:

### 1. 🧠 Socratic Step Solver & AI Tutor
- Students paste any tricky homework or textbook problem.
- Instead of cheating or providing direct answers, the AI generates:
  - **💡 Step 1: Conceptual Intuition & Hint**
  - **📐 Step 2: Governing Mathematical Formula in LaTeX**
  - **🔬 Step 3: Step-by-Step Derivation Breakdown**
  - **✅ Step 4: Self-Check Question** to test student understanding.

### 2. ⏳ 45-Minute Pomodoro Revision Sprints
- Transforms intimidating chapters into 3 timed mastery blocks:
  - `00 - 15 Mins`: Foundational laws & core variable definitions.
  - `15 - 35 Mins`: High-yield exemplar problem solving and common trap alerts.
  - `35 - 45 Mins`: Rapid recall quiz & concept mindmap synthesis.

### 3. 🗂️ Active Recall Flashcards Deck
- Generates interactive 3D flip cards with memory cues and formula derivations for spaced repetition before exams.

### 4. 📋 Solution Key & Self-Grading Rubrics
- Provides official step-by-step marking schemes with marks distribution (e.g. `[1 Mark]`, `[2 Marks]`) so students learn exactly how examiners award marks.

## ⚡ Universal Prompt Optimizer (Cross-Platform AI Bridge)

For users unfamiliar with prompt engineering, the **Prompt Optimizer** turns simple one-line requests into production-grade master prompts:

```
[ Simple User Idea ]  ──►  [ DeepHub Prompt Engine ]  ──►  [ Battle-Tested Master Prompt ]
"write math test"          • CO-STAR Framework              • Role: Senior Academic Examiner
                           • Anti-Hallucination Shield       • Multi-Step Delimiters
                           • XML Structured Tags            • Negative Constraints
                           • Output JSON / Table Schema     • Ready for ChatGPT, Claude, Gemini
```

### Supported Platforms:
- **ChatGPT / GPT-4o & o1**: Enforces structured markdown headings, step-by-step workflows, and zero conversational fluff.
- **Claude 3.5 Sonnet**: Injects Anthropic-native XML tags (`<role>`, `<context>`, `<instructions>`, `<constraints>`, `<output_format>`).
- **Google Gemini 2.0**: Multi-modal reasoning and large context grounding.
- **DeepSeek R1 / V3**: Explicit step-by-step mathematical reasoning and verification checks.
- **Perplexity AI**: Academic citation directives and search filters.
- **Midjourney v6.1**: Cinematic aspect ratios (`--ar 16:9`), octane render engines, volumetric lighting, and camera lenses.

- **⚡ Turbo Brain Recall Chips**: 1-Click interactive chips rendered across all tools for seamless prompt continuity without re-typing.

## 🚀 Quickstart & Local Setup

### Prerequisites
- Node.js 18+ or 20+
- npm or yarn

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/deephubai/deephubai.git
cd deephubai

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

### Production Build & Type Verification
```bash
# Type check with TypeScript compiler
npx tsc --noEmit

# Compile production bundle
npm run build
```

## 🔒 Security, Data Privacy & NEP-2020 / FERPA Compliance

- **Zero Data Training**: User prompts and school examination papers are never used to train foundational AI models.
- **Ephemeral Processing**: OCR scans and student homework submissions are processed in memory and discarded upon session completion.
- **Client-Side Document Assembly**: DOCX, PPTX, and PDF binaries are packaged directly in the client browser using WebAssembly and Web Workers.
